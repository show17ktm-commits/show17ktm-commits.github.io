プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-26

1. 概要 / Overview

Shorts Uploader（以下「本ツール」）は、運営者本人が自分の YouTube チャンネルに動画をアップロードするための個人用ツールです。本ツールは YouTube API Services を利用しています。

Shorts Uploader ("the Tool") is a personal tool used by its owner to upload videos to the owner's own YouTube channel. The Tool uses YouTube API Services.

2. 取得する情報 / Information We Access

本ツールは Google OAuth により、YouTube への動画アップロード権限（https://www.googleapis.com/auth/youtube.upload）のみを取得します。視聴履歴、連絡先、その他の個人情報にはアクセスしません。

The Tool requests only the YouTube upload scope (https://www.googleapis.com/auth/youtube.upload) via Google OAuth. It does not access watch history, contacts, or any other personal data.

3. 利用目的 / How We Use Information

取得した権限は、運営者が制作した動画とそのタイトル・説明文を運営者自身のチャンネルにアップロードする目的にのみ使用します。

The authorization is used solely to upload videos (with titles and descriptions) created by the owner to the owner's own channel.

4. 保存 / Storage

認証トークンは運営者のパソコン内にのみ保存され、外部のサーバーには送信・保存されません。

OAuth tokens are stored only on the owner's computer and are not sent to or stored on any other server.

5. 第三者への提供 / Sharing

取得した情報を第三者に提供・販売・共有することはありません。

We do not sell, share, or disclose any information to third parties.

6. アクセスの取り消し / Revoking Access

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定ページ（https://myaccount.google.com/permissions）からいつでも取り消せます。取り消し後、保存されたトークンは削除します。

You can revoke the Tool's access at any time via https://myaccount.google.com/permissions. Stored tokens are deleted upon revocation.

7. 関連する規約 / Related Policies

本ツールを利用することで、YouTube 利用規約および Google プライバシーポリシーに同意したものとみなされます。

By using the Tool, you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.

  • YouTube Terms of Service
  • Google Privacy Policy

本ツールによる Google API から受け取った情報の使用は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
